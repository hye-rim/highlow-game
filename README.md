# 하이로우 🃏

다음 카드가 지금보다 높을지 낮을지 맞히며 점수를 쌓는 카드 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 카드 한 벌(52장)을 섞어 한 장씩 넘긴다. 다음 카드가 **높다 ▲ / 낮다 ▼** 를 고른다. A 가 가장 낮고 K 가 가장 높다. 같은 숫자면 무승부(점수·하트·연속 그대로)
- 맞히면 **10 ÷ 맞힐 확률** 점(확률 50% → 20점, 10% → 100점). 연속으로 맞힐수록 배수가 붙는다(+10%씩, 최대 ×2)
- 틀리면 하트 하나. 하트가 다 없어지면 끝. 52장을 다 넘기면 남은 하트 하나당 +50
- 🔄 바꾸기 3번: 지금 카드를 맞히지 않고 다음 카드로 넘긴다 (애매한 7 같은 카드를 피할 때)
- **쉬움**: 하트 5개, 버튼에 확률과 맞혔을 때 점수, 아래에 아직 안 나온 카드 표. **보통**: 하트 3개, 나온 카드를 직접 기억해야 한다
- 메달: 동 250 · 은 400 · 금 650점. 최고 점수는 모드별 `highlowBestEasy` · `highlowBestNormal`, 로비 표시용은 둘 중 큰 값 `highlowBest`
- PC: ↑ 높다 · ↓ 낮다 · Space 바꾸기 · M 소리

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력·소리는 `game.js`.
